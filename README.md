# 📚 我的知识库

> 用 Markdown 记录、组织、连接一切值得记住的东西。

## 目录

| 分类 | 说明 |
|------|------|
| [00-inbox](00-inbox/) | 收件箱 - 临时想法，待整理 |
| [10-notes](10-notes/) | 学习笔记 - 读书、课程、文章 |
| [20-projects](20-projects/) | 项目记录 - 做过的事、踩过的坑 |
| [30-life](30-life/) | 生活与思考 - 随笔、复盘、灵感 |
| [90-archive](90-archive/) | 归档 - 不再活跃但值得留存 |

## 怎么用

1. **随手记** → 写进 `00-inbox/`，格式随意
2. **定期整理** → 每周挑时间，把 inbox 里的内容分类到对应目录
3. **建立连接** → 用 `[[双链]]` 把相关笔记连起来
4. **命名规范** → `YYYY-MM-DD-简短标题.md`
