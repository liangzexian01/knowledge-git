# 关闭开机自启项操作手册

## 背景

在 Windows 系统中，过多的开机自启项会严重拖慢系统启动速度并占用后台资源。常见的自启项主要托管于两个位置：**注册表**（`HKCU` 或 `HKLM` 下的 `...\CurrentVersion\Run`）和 **启动文件夹**（Startup）。

本手册旨在规范通过 `pc-control` 通道禁用自启项的操作流程。本次实践已成功关闭以下自启项：
*   **Ollama**（位于 Startup 文件夹的 `.lnk` 快捷方式）
*   **酷狗**（`KuGou8` 注册表项）
*   **360画报**（`360huabao` 注册表项）
*   **夸克**（`quark` 及 `QuarkUpdater` 注册表项）

**⚠️ 核心强调**：在进行任何删除/移除操作前，**必须先将配置备份至 `C:\Users\梁泽贤\.dsh\backup\` 目录**，以防系统异常或需要恢复。

---

## 步骤

### 1. 列出当前自启项（侦察阶段）
通过 `pc-control` 通道执行以下 PowerShell 命令，获取当前系统所有自启项的详细信息（包含名称、位置、命令、所在路径）：
```powershell
Get-CimInstance Win32_StartupCommand | Select-Object Name, Location, Command
```

### 2. 创建备份目录
确保备份目录存在，执行：
```powershell
New-Item -ItemType Directory -Force -Path "C:\Users\梁泽贤\.dsh\backup\"
```

### 3. 执行备份与关闭操作

#### 3.1 关闭 Ollama (Startup 文件夹)
*   **备份**：将快捷方式从启动文件夹移动到备份目录。
    ```powershell
    # 获取当前用户 Startup 路径并移动 .lnk 文件
    $startupPath = [Environment]::GetFolderPath('Startup')
    Move-Item -Path "$startupPath\Ollama.lnk" -Destination "C:\Users\梁泽贤\.dsh\backup\" -Force
    ```

#### 3.2 关闭酷狗 (注册表 KuGou8)
*   **备份**：导出注册表值到备份目录。
    ```powershell
    reg export "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" "C:\Users\梁泽贤\.dsh\backup\KuGou8_reg_backup.reg" /y
    ```
*   **删除**：移除指定键值。
    ```powershell
    Remove-ItemProperty -Path "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" -Name "KuGou8" -ErrorAction SilentlyContinue
    Remove-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" -Name "KuGou8" -ErrorAction SilentlyContinue
    ```

#### 3.3 关闭 360画报 (注册表 360huabao)
*   **备份**：导出注册表值。
    ```powershell
    reg export "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" "C:\Users\梁泽贤\.dsh\backup\360huabao_reg_backup.reg" /y
    ```
*   **删除**：移除指定键值。
    ```powershell
    Remove-ItemProperty -Path "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" -Name "360huabao" -ErrorAction SilentlyContinue
    Remove-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" -Name "360huabao" -ErrorAction SilentlyContinue
    ```

#### 3.4 关闭夸克 (注册表 quark 及 QuarkUpdater)
*   **备份**：导出注册表值。
    ```powershell
    reg export "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" "C:\Users\梁泽贤\.dsh\backup\Quark_reg_backup.reg" /y
    ```
*   **删除**：批量移除夸克相关键值。
    ```powershell
    Remove-ItemProperty -Path "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" -Name "quark" -ErrorAction SilentlyContinue
    Remove-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" -Name "quark" -ErrorAction SilentlyContinue
    Remove-ItemProperty -Path "HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" -Name "QuarkUpdater" -ErrorAction SilentlyContinue
    Remove-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" -Name "QuarkUpdater" -ErrorAction SilentlyContinue
    ```

---

## 验证

执行完所有删除和移除操作后，重新查询自启列表，确认目标项已消失：
```powershell
# 筛选查询结果，确认无 Ollama, KuGou8, 360huabao, quark, QuarkUpdater
Get-CimInstance Win32_StartupCommand | Where-Object { $_.Name -match "Ollama|KuGou8|360huabao|quark|QuarkUpdater" }
```
*   **预期结果**：上述命令执行后返回空值。
*   **文件验证**：前往 `C:\Users\梁泽贤\.dsh\backup\` 检查，应存在 `Ollama.lnk` 及各对应 `.reg` 备份文件。
*   **最终验证**：重启计算机，确认开机后这些程序不再自动弹出。

---

## 回滚

若发现误删或业务需要恢复某项的自启功能，通过 `pc-control` 通道利用备份目录中的文件进行恢复：

### 恢复 Startup 文件夹项 (如 Ollama)
```powershell
$backupPath = "C:\Users\梁泽贤\.dsh\backup\Ollama.lnk"
$startupPath = [Environment]::GetFolderPath('Startup')
Move-Item -Path $backupPath -Destination $startupPath -Force
```

### 恢复注册表项 (如 酷狗、360画报、夸克)
直接导入之前备份的 `.reg` 文件至注册表：
```powershell
# 以恢复酷狗为例（根据实际需要替换文件名）
reg import "C:\Users\梁泽贤\.dsh\backup\KuGou8_reg_backup.reg"

# 恢复360画报
reg import "C:\Users\梁泽贤\.dsh\backup\360huabao_reg_backup.reg"

# 恢复夸克
reg import "C:\Users\梁泽贤\.dsh\backup\Quark_reg_backup.reg"
```
*执行回滚导入后，建议再次使用 `Get-CimInstance Win32_StartupCommand` 确认对应自启项已恢复显示。*
