# GitHub 知识库搭建

**时间**：2026-10-22
**状态**：已上线

## 背景

想要一个属于自己的知识库，能随时记录、随时查看，不用依赖第三方服务。

## 方案

选型对比了以下框架：

| 方案 | Star | 优点 | 缺点 |
|------|------|------|------|
| AFFiNE | 73.7k | 功能全，像 Notion | 需要自己部署，重 |
| Joplin | 56.8k | 跨平台，端到端加密 | 主要是笔记 App |
| Outline | 41.0k | 团队 Wiki 体验好 | 需要服务器 |
| Trilium | 38.4k | 层级知识树，双向链接 | 部署有一定门槛 |
| **Quartz** | 13.4k | Markdown → 静态网站 | 需要构建 |

**最终选择**：纯 Markdown + GitHub 托管

理由：
1. 不依赖任何服务，永远能看
2. 手机、电脑都能编辑
3. 免费，无到期风险
4. 可随时升级成静态网站

## 结果

- 仓库：`liangzexian01/knowledge-git`
- 结构：inbox / notes / projects / life / archive
- 可直接在 GitHub 上编辑，也会自动同步

## 复盘

1. **选的方案偏简单是对的** — 复杂方案容易搁置
2. **目录结构要预先设计好** — 否则会变成垃圾堆
3. **坚持整理比工具有用**

## 踩过的坑

- GitHub 仓库名不能有空格，会自动转成连字符
- 国内访问 GitHub 建议配好网络
