## 二、传统 CV 复习速查

四段代码串起灰度、边缘、轮廓、形态学。

```python
import cv2, numpy as np

img = cv2.imread("test.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)              # 灰度
edges = cv2.Canny(gray, 100, 200)                          # Canny 边缘
_, th = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)   # 二值化
kernel = np.ones((5, 5), np.uint8)
morph = cv2.morphologyEx(th, cv2.MORPH_CLOSE, kernel)      # 闭运算连断点
contours, _ = cv2.findContours(morph, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
for c in contours:
    area = cv2.contourArea(c)
    if area > 100:                                         # 过滤噪点
        x, y, w, h = cv2.boundingRect(c)
        cv2.rectangle(img, (x, y), (x + w, y + h), (0, 255, 0), 2)
cv2.imshow("result", img); cv2.waitKey(0)
```

## 三、用 Ultralytics YOLOv8 做目标检测

**推理一张图**（首次运行会自动下载权重）：

```python
from ultralytics import YOLO
model = YOLO("yolov8n.pt")             # n 最小，速度最快
results = model("bus.jpg")
results[0].save("bus_out.jpg")         # 可视化结果另存
# 读取检测框和类别
for box in results[0].boxes:
    print(box.cls.item(), box.conf.item(), box.xyxy.tolist())
```

**训练自己数据集的最小结构**（YOLO 格式，一张图对应一个 .txt）：

```
dataset/
  images/train/  images/val/
  labels/train/  labels/val/
  data.yaml
```

`data.yaml` 内容：

```yaml
path: ./dataset
train: images/train
val: images/val
names: {0: defect, 1: scratch}    # 你的类别名
```

训练只需一行：

```python
from ultralytics import YOLO
model = YOLO("yolov8n.pt")                    # 也可从 yaml 从头训
model.train(data="dataset/data.yaml", epochs=50, imgsz=640, batch=8)
```

## 四、边缘部署：导出 ONNX 并推理

```python
from ultralytics import YOLO
YOLO("yolov8n.pt").export(format="onnx", imgsz=640)   # 生成 yolov8n.onnx
```

ONNX Runtime 推理（不依赖 PyTorch，适合工控机）：

```python
import onnxruntime as ort, numpy as np, cv2

sess = ort.InferenceSession("yolov8n.onnx", providers=["CPUExecutionProvider"])
img = cv2.imread("bus.jpg"); img = cv2.resize(img, (640, 640))
x = img[:, :, ::-1].transpose(2, 0, 1)[None].astype(np.float32) / 255.0  # BGR->RGB, NCHW
out = sess.run(None, {sess.get_inputs()[0].name: x})[0]  # (1, 84, 8400)
print(out.shape)
```

提示：若工控机是 Intel 平台，可 `pip install openvino`，用 `mo` 转换或 `export(format="openvino")`，再 `ov.Core().compile_model` 推理，速度通常比 ONNX CPU 更快。

## 五、SAM 零样本分割尝鲜

Segment-Anything 能在无训练的情况下分割任意目标。

```python
# pip install segment-anything
import cv2
from segment_anything import sam_model_registry, SamPredictor
sam = sam_model_registry["vit_b"](checkpoint="sam_vit_b.pth")
predictor = SamPredictor(sam)

img = cv2.cvtColor(cv2.imread("test.jpg"), cv2.COLOR_BGR2RGB)
predictor.set_image(img)
masks, scores, _ = predictor.predict(
    point_coords=[[300, 200]], point_labels=[1]   # 点一个正样本点
)
print(masks.shape, scores)                        # 掩膜 + 置信度
```

工业场景可接 YOLO 的框作为 SAM 的 `box=` 输入，实现"检测 + 精细分割"，做缺陷面积测量特别实用。

## 六、常见数据集速取

| 数据集 | 场景 | 获取方式 |
|---|---|---|
| COCO | 通用 80 类 | `https://cocodataset.org`，Ultralytics 自动下载 |
| VisDrone | 无人机航拍目标 | GitHub `VisDrone/VisDrone-Dataset` |
| NEU-DET | 钢材表面缺陷 | Kaggle 搜索 `NEU surface defect` |
| 医学分割(如 ISIC) | 皮肤病变 | `https://challenge.isic-archive.com` |

小贴士：先拿公开数据跑通流程，再用手机拍照 + LabelImg 或 `Ultralytics HUB` 标注自己的小数据集（几十张即可出效果）。

## 七、5 个可落地的毕设/竞赛选题

1. **钢材缺陷检测**：NEU-DET + YOLOv8，对比传统 Canny 与深度学习召回率，好写论文也好出图。
2. **无人机视角行人计数**：VisDrone + YOLOv8s，加 SORT 跟踪做客流统计。
3. **生产工件尺寸测量**：传统标定 + 轮廓最小外接矩形，配合 YOLO 定位目标区域，精度可做到 mm 级。
4. **SAM 辅助的缺陷面积评估**：YOLO 检测粗定位 → SAM 精分割 → 计算缺陷像素面积，是当下热门組合拳。
5. **嵌入式智能分拣演示**：YOLOv8 训练自定义物体 + 导出 ONNX/OpenVINO，在树莓派或工控机上跑实时推理，接串口控制舵机。

**学习路径建议**：先把第二、三节跑通，再攻克第四节部署，最后用第六节数据练手、第七节选题收尾。祝毕设顺利！
