# 机器视觉中的深度学习：从入门到能干活

> 学习笔记 · 系统打底篇
> 适用对象：会 Python + OpenCV，刚接触深度学习的大专机器视觉专业学生
> 目标：看完能知道"深度学习在机器视觉里到底干嘛、怎么干、别踩哪些坑"


## 一、深度学习解决机器视觉的什么

传统 CV（OpenCV 那一套）最擅长的是**规则明确**的活：阈值分割、形态学、模板匹配、边缘检测、轮廓测量。这类任务快、省、可解释，产线上大量在用。

但它有三个绕不过去的痛点：

1. **鲁棒性差**：光照一变、反光一强、背景一乱，阈值就崩。你调好的参数换个工位就失灵。
2. **特征靠人写**：你要自己设计"什么样的纹理是划痕""什么形状是缺陷"，人脑想不出的特征，代码也写不出。
3. **分类识别基本无能**：让 OpenCV 判断这是猫还是狗、是良品还是某类特定缺陷，几乎没法做。

深度学习补的正是这三块：

- **自动学特征**：你给图片和标签，网络自己找"该看哪里"，不用你手写规则。
- **抗干扰强**：数据里见过光照变化、角度变化，模型就能泛化（但不是万能，见第六节）。
- **能做高维判别**：分类、检测、分割、生成，传统 CV 很难做的它都能做。

一句话定位：**传统 CV 干"确定性测量"，深度学习干"不确定的识别与理解"。** 产线上常见做法是二者混合——深度学习定位+分类，OpenCV 做尺寸测量和结果复核。


## 二、核心概念一张图说清

用一个"教徒弟认缺陷"的比喻串起来：

| 概念 | 比喻 | 说明 |
|---|---|---|
| **张量 Tensor** | 一摞照片 | 数据的容器。图片是 `(高, 宽, 通道)`，一批图就是 `(批, 高, 宽, 通道)` |
| **卷积 Convolution** | 拿放大镜一片片扫 | 一个小窗口（如 3×3）在图上滑动做加权求和，提取局部特征（边、角、纹理） |
| **池化 Pooling** | 隔几个像素取最大/平均 | 降分辨率、留主信息、省算力，同时带来一点平移不变性 |
| **激活 Activation** | 给 neurons "通电" | 非线性函数（ReLU 最常用），没有它网络再深也只是线性变换 |
| **损失 Loss** | 考试扣分 | 衡量预测和标签差多少，训练就是"想办法少扣分" |
| **反向传播 Backprop** | 顺着错题找原因 | 用链式法则算出每个参数"该往哪调"，配合优化器（SGD/Adam）更新 |
| **Epoch** | 把课本过一遍 | 全部训练数据过一遍叫 1 epoch，通常要几十上百个 epoch |

**训练的本质**：反复"前向算预测 → 算损失 → 反向传播调参数"，让损失下降。就这么朴素。

极简 PyTorch 片段（看懂结构即可）：

```python
import torch, torch.nn as nn

# 一个极简 CNN：卷积提特征 + 池化降维 + 全连接分类
model = nn.Sequential(
    nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # 提特征、降一半
    nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Flatten(),                   # 展平成一维
    nn.Linear(32 * 56 * 56, 10),    # 假设输入 224x224，输出 10 类
)
loss_fn = nn.CrossEntropyLoss()             # 分类标配损失
opt = torch.optim.Adam(model.parameters(), lr=1e-3)  # 优化器
```


## 三、主流网络家族与适用场景

不用背，要会"按任务选网络"。

**CNN 家族（图像分类/特征提取的底座）**
- **ResNet**：加了"残差连接"，让网络能堆很深不退化。工业上最稳的 baseline，50/101 常用。
- **EfficientNet**：同精度下更省算力，边缘设备友好。
- 场景：缺陷分类、良品/不良品判断、特征主干。

**Transformer 家族（ViT）**
- 把图像切成小块当"词"，用注意力机制建模全局关系。
- 数据量大时很强，小数据上不如 CNN 稳。适合有大规模数据或做预训练微调。

**目标检测（找位置+分类）**
- **YOLO**：单阶段、快，工业首选（Ultralytics 生态成熟）。产线实时检测基本用它。
- **SSD**：较早的单阶段，轻量，可了解。
- **Faster R-CNN**：两阶段、精度高但慢，适合精度优先、速度次要的场景。

**分割（像素级）**
- **U-Net**：医学/工业缺陷分割经典，结构对称、好训。
- **Mask R-CNN**：检测+实例分割一体。
- **SAM**：大模型"点一下就能分割"，适合做标注辅助或通用分割，但资源要求高。

**生成（造数据、造图）**
- **GAN**：生成逼真图像，可用于数据增强（如生成缺陷样本）。
- **Diffusion**：当前主流生成方案，质量高，但训练/推理重。

**选择口诀**：分类型任务先上 ResNet/EfficientNet；要位置上 YOLO；要像素级上 U-Net；数据太少先想"能不能用传统 CV 或增强"；预算/算力紧就选轻量模型。


## 四、一条标准训练流水线

**数据 → 标注 → 增强 → 模型 → 训练 → 评估 → 部署**

| 步骤 | 做什么 | 常用工具 |
|---|---|---|
| 数据 | 采集、清洗、去重、分训练/验证/测试集 | 脚本、`labelImg`、`CVAT`、`Roboflow` |
| 标注 | 分类标类别、检测画框、分割画掩膜 | `LabelImg`、`CVAT`、`Label Studio`、`SAM` 辅助 |
| 增强 | 翻转、旋转、亮度、裁剪、Mosaic | `Albumentations`、`torchvision.transforms` |
| 模型 | 选 backbone + 任务头，或直接用现成框架 | `torchvision`、`timm`、`ultralytics` |
| 训练 | 设超参、跑 epoch、看 loss 曲线 | PyTorch + 单卡/多卡，`tensorboard` 看曲线 |
| 评估 | 分类看 Acc/F1，检测看 mAP，分割看 IoU | `sklearn`、框架自带评估 |
| 部署 | 导出 ONNX → 优化 → 上 CPU/边缘 | `ONNX`、`OpenVINO`、`TensorRT`、`ONNX Runtime` |

**关键提醒**：数据划分必须**互不重叠**（同一次拍摄的多张图别拆到训练和验证两边，否则虚高）。增强只在训练集做，验证/测试集不要增强。


## 五、常用框架与生态

- **PyTorch（主推）**：论文和工业双主流，动态图好调试，学它性价比最高。
- **MMDetection（OpenMMLab）**：检测/分割全家桶，配置化训练，适合研究和复现。
- **Ultralytics（YOLO 官方）**：几行代码训 YOLO，工程落地快，新手最爱。
- **Detectron2（Meta）**：经典检测分割框架，生态成熟。
- **部署链路**：PyTorch 模型 → 导出 **ONNX**（跨平台中间格式）→ **OpenVINO**（Intel CPU/核显加速）或 **TensorRT**（NVIDIA GPU 加速）→ 上产线。

```python
# 导出 ONNX（部署第一步）
dummy = torch.randn(1, 3, 224, 224)          # 假输入，确定形状
torch.onnx.export(model, dummy, "model.onnx",
                  input_names=["input"], output_names=["output"])
```


## 六、新手最常踩的 10 个坑

1. **过拟合**：训练集准、测试集崩。→ 加数据、加增强、加 dropout、早停、用更小模型。
2. **数据太少**：几十张就想训。→ 迁移学习（用预训练权重微调）+ 强增强，别从零训。
3. **类别不平衡**：良品一大堆、缺陷几张。→ 重采样、类权重、focal loss，评估看 F1 而不是 Accuracy。
4. **标注质量差**：框画歪、漏标、类别标错。→ 标注规范 + 抽检复核；垃圾标注喂不出好模型。
5. **学习率瞎设**：太大震荡不收敛，太小训到天荒地老。→ 先 `1e-3` 试，用 warmup + 余弦衰减。
6. **GPU 显存爆**：batch 开太大。→ 降 batch、用 `torch.cuda.amp` 混合精度、梯度累积。
7. **忘记归一化**：像素 `0~255` 直接进网络。→ 统一 `/255`，或按预训练模型的 mean/std 标准化。
8. **训验分布不一致**：训练图亮、测试图暗；训练单相机、测试换相机。→ 采集要覆盖真实变化。
9. **指标选错**：不平衡任务只看 Accuracy，模型"全猜多数类"也 90%+。→ 用 F1/Recall/mAP，看混淆矩阵。
10. **不做 baseline**：上来就怼复杂模型，结果说不清好坏。→ 先跑通一个简单 baseline（如 ResNet18 微调），再逐步迭代。

```python
# 归一化 + 增强：训练集才做增强
import torchvision.transforms as T
train_tf = T.Compose([
    T.Resize((224, 224)),
    T.RandomHorizontalFlip(), T.ColorJitter(0.2, 0.2),  # 增强
    T.ToTensor(), T.Normalize([0.485,0.456,0.406], [0.229,0.224,0.225]),
])
```


## 七、给大专生的 6 个月学习路径

| 阶段 | 目标 | 每周做什么 | 小项目 |
|---|---|---|---|
| **1 月** | 打通 PyTorch 训练流程 | 学张量、autograd、`nn.Module`；跑通 MNIST/CIFAR10 | 手写 CNN 分类 CIFAR10，画出 loss 曲线 |
| **2 月** | 会迁移学习 | 用 `timm`/`torchvision` 预训练模型微调；理解学习率、增强 | 猫狗分类，或用自采图片分类 `螺栓/螺母/垫片` |
| **3 月** | 会目标检测 | 学 YOLO 标注格式、`Ultralytics` 训练 | 自采数据集训练 YOLO 检测 `划痕/凹坑` |
| **4 月** | 会语义分割 | 学 U-Net 结构、IoU 评估；用 `Albumentations` | 缺陷分割小项目，输出掩膜并可视化 |
| **5 月** | 会部署 | 学 ONNX 导出、OpenVINO 加速、简单推理服务 | 训练好的模型导出 ONNX，OpenVINO 在 CPU 跑通 |
| **6 月** | 综合做毕设 | 全流程：数据→标注→训练→评估→部署→写文档 | 完整课题（见下节） |

每周节奏建议：**2~3 天看/跑代码，2 天做小项目，1 天复盘写笔记**。重点不是看视频，而是"每学完一个概念就用最小代码验证一遍"。


## 八、5 个适合毕设/竞赛的选题（带数据集）

1. **工业表面缺陷检测（分类+检测）**：数据集用 **NEU-DET**（钢材表面缺陷）、**MVTec AD**（异常检测基准）。做：分类→检测→部署三件套，含对比实验。
2. **安全帽/反光衣佩戴检测（YOLO）**：数据集用 **SHWD**（安全帽）或用 Roboflow 公开集。做：YOLO 检测 + 部署到 CPU 实时视频。
3. **垃圾分类识别（分类/检测）**：数据集用 **TrashNet** 或华为云垃圾分类公开数据。做：迁移学习分类 + 轻量模型对比（ResNet vs EfficientNet）。
4. **医学图像分割（U-Net）**：数据集用 **ISIC 皮肤病变** 或 **DRIVE 眼底血管**。做：U-Net 分割 + IoU 评估 + 可视化。
5. **遥感/无人机目标检测**：数据集用 **VisDrone**（密集小目标）。做：YOLO 小目标改进（数据增强/多尺度），对比 mAP。

选题建议：**优先选"你有渠道采到真实图片"的题目**，公开数据集用来打底，自采数据用来出彩。毕设加分项是"部署到边缘设备跑通 + 有对比实验"。


## 结语

深度学习在机器视觉里不是"取代 OpenCV"，而是把"识别"这块硬骨头啃下来。学习路径记住三句话：

1. **先跑通，再理解，最后优化**——不要一上来啃公式。
2. **baseline 是命根子**——没有对比，说不清好坏。
3. **数据决定天花板，模型只是逼近天花板**——时间多花在数据和标注上，不亏。
