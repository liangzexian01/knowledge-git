# Markdown 语法速查

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 强调

```markdown
**粗体**
*斜体*
~~删除线~~
`行内代码`
```

## 列表

```markdown
- 无序列表
  - 嵌套

1. 有序列表
2. 第二项

- [ ] 待办
- [x] 已完成
```

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片描述](path/to/image.png)
[[双链笔记]]
```

## 代码块

````markdown
```python
print("hello")
```
````

## 表格

```markdown
| 列1 | 列2 |
|-----|-----|
| A   | B   |
```

## 引用

```markdown
> 这是一段引用
```

## 分割线

```markdown
---
```
